MotionCare AI — MSK multilingual submission package

Scope: low back, neck/shoulder, knee and hip rehabilitation. Educational prototype only.

Public deployment (Render Static Site):
1. Upload index.html, manifest.webmanifest, sw.js to the root of a GitHub repository.
2. In Render choose New + -> Static Site and connect that repository.
3. Leave Build Command empty; set Publish Directory to `.`; deploy.
4. Render gives an HTTPS onrender.com URL. Test it on phone, tablet and computer.

GitHub Pages alternative: repository Settings -> Pages -> Deploy from branch -> main -> /(root).

Language selector supports Chinese, English and Korean for key interface labels; some detailed text may remain Chinese.

This static package has no secure cloud database, user authentication, cross-device patient-data synchronization, or real AI pose estimation. Do not enter real patient data. Not for diagnosis or clinical decisions.
